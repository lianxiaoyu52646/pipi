# 皮皮 V5.11 · Android Studio 导航与交互整合版

## 本版交付边界
此包基于 V5.10.9 完整工程，并应用了“后台缓存进度显示修复”的两项代码文件；已经整合 V5.11 的导航修改。不是旧版增量补丁，无需从 V5.10.3 逐个叠加补丁。

## 新版页面
- 底部导航：今日 / 词书 / 阅读 / 复习 / 工具。
- 今日：继续背词和阅读、今日待复习信息保持。
- 词书：打开正在学习的词书后，可直接点击顶部词书名称呼出切换抽屉，各本书继续沿用既有独立进度；词书展示及“下滑算已会、点击不会收录生词”机制不改。
- 复习：新增“生词本”快捷筛选（所有已标记、未掌握生词），其余今日到期、阅读生词、学习中、已掌握等筛选保留。
- 阅读：9本已内置英文原著在书架显示；阅读器返回到书架，书架返回到来源模块。原有护眼、上下滚动、点词释义抽屉与 Kokoro 朗读保留。
- 工具：集中展示离线语音缓存、离线词典、导出/恢复、学习数据、设置与原有专项训练；后台缓存进行时底部工具图标显示小提示点，工具页显示已生成的片段数。
- 返回：Android 返回键先关弹窗 / 返回书架，再沿页面历史返回；主页面切换记录滚动位置。独立页面通过本机 sessionStorage 保存来源，缓存页和备份页返回时优先到来源页面。

## 在 Windows 的 Android Studio 里构建
1. 下载 `Pipi_V5.11_AndroidStudio_Integrated_Project.zip`，建议使用“全部解压”解压到一个**新目录**，如 `C:\Users\74787\Downloads\Pipi_V5.11`。不要把此工程混进旧的 `9 (2)`、`3` 目录。
2. 旧工程 `C:\Users\74787\Downloads\9 (2)` 保留不动。V5.11 的 Gradle 脚本会尝试从该目录导入本机 Piper、Kokoro 和 sherpa-onnx AAR；找不到时会尝试 `Downloads\3`。模型文件和 AAR 不在本 ZIP 中。
3. 在 Android Studio 中打开新目录并执行 `:app:assembleDebug`。若语音模型缺失会在 `verifyOfflineVoiceAssets` 阶段报错，不能视作成功 APK。
4. 成功打包后 APK 地址是 `新工程目录\app\build\outputs\apk\debug\app-debug.apk`。
5. 先导出学习数据备份。保留手机旧 App；用相同包名 `com.sprint7.offline`、相同签名直接覆盖安装时，Android 通常保留 `filesDir` 音频缓存与学习数据。**不要卸载旧 App、不要清除应用数据**。如果签名不一致，不要为了安装而卸载旧 App。

## 重要限制
- 本次在当前环境做了 Chromium 的 DOM/事件交互测试、Node.js 导航单元测试、源码语法与历史数据资源测试；**未在用户手机进行真实 Android APK 构建及 Android 返回键、Kokoro/后台生成的真机验收**。
- 第10本《汤姆·索亚历险记》全文资源仍缺失；发布 Release 的内容校验会阻止发布。Debug 编译供个人测试。
- 本版以跳转和交互为主，不宣称解决了 Kokoro 实时合成慢、长时间连续朗读或后台锁屏时厂商电源管理限制。
- ZIP 文件使用英文 ASCII 文件名，避免某些 Windows 下载器把中文 ZIP 文件名编码成 `%E7...` 引发识别问题。

## 真机核心验收建议
1. 今日继续背词两次点击以内进入；7本词书进度相互独立。
2. 词书静止一分钟无自行跳动；退出再进入从下一词续学。
3. 工具页滑动到中部、切复习、Android 返回键回工具原位置。
4. 阅读打开一部原著、点词后关闭释义抽屉，当前阅读句子保持；退出阅读器回书架，退出书架回之前的模块。
5. 工具 → 语音缓存 → 返回工具，缓存数字仍在增加；锁屏后台任务由前台服务负责，运行结果应实测。
6. 同样签名覆盖安装后学习记录、`filesDir` 中已有的语音缓存仍在。
7. 安卓不同机型的 320～430 CSS 像素宽度上，按钮不溢出。
