# 皮皮 V5.12.20 · 全书语音缓存长时间运行稳定性修复

**适用基线：V5.12.19**。这是源码增量补丁，不是已经签名的 APK；基于前一版继续修复长时间无人值守时的潜在停滞。

## 本次确实修改的内容

1. **Kokoro 进程锁限时等待**：缓存线程改为每轮最多等待 120 秒，再隔 30 秒重试。不会强抢正在阅读器进程使用的模型；`waiting_model` 超过 3 分钟增加明确诊断，避免误认为正在真实产出 PCM。旧版为不限制等待时间，且监控没有覆盖这个阶段。
2. **坏片段自动重试上限**：每个唯一内容哈希最多 8 次自动失败。达到上限仍保留为“未完成”，不会虚报 100%；其余可缓存片段先行生成。当全部剩余片段都达到上限时，暂停自动任务并标为“需要处理”，停止耗电重试；再次**手动**点“开始”可重置这些隔离记录并重试。升级保留现有失败次数，数据库不执行丢失式迁移。
3. **长时间失败等待不霸占模型**：进入异常片段的冷却等待或最终核验前先释放已加载 Kokoro 和跨进程锁，避免阅读器长期被等待中的批处理阻塞。
4. **手机重启后重新安排恢复检查**：增加 `RECEIVE_BOOT_COMPLETED` 和广播接收器，仅在用户之前明确开启连续缓存时，重新安排一次恢复闹钟。**不会从广播直接强行启动前台服务**；Android/小米可能限制后台启动，记录该限制，用户回到前台时仍可恢复。
5. **版本升级**：`versionCode 49`，`versionName 5.12.20`。

### 保留的旧能力

- V5.12.19 的按音色/语速的缓存档案保护及既有 PCM 自动找回；
- SQLite 已完成片段、文件校验、异常恢复日志、生成速度统计；
- 20 本离线原著、FSRS、词书、生词本、Piper 与 Kokoro。

**未修改 PCM 文件结构、SQLite 数据库版本或缓存文件夹位置。补丁不删除手机内任何 PCM/SQLite 文件。**

## 安装方法

1. 在电脑上备份原工程 `C:\Users\74787\Downloads\pipi`，用旧版 App 导出学习记录。
2. 解压 `皮皮_V5.12.20_无人值守缓存稳定性_增量补丁_适用V5.12.19.zip` 到该工程根目录，按路径覆盖。
3. 在 Android Studio 构建 `:app:assembleDebug`，使用原来相同签名覆盖安装。**禁止卸载旧 App 或清空数据**。
4. 打开全书缓存页，核对是否恢复了正确的音色和语速；对比升级前后的累计已完成段数。
5. 做一次锁屏 8–12 小时真机测试，再评估连续几天的可靠性。观察真实写盘时间、模型等待日志、异常恢复次数、已完成段数是否递增。

## 验收范围及限制

当前环境完成：35 项 JS 测试、全书资源结构核对、SQLite 队列模拟、Kotlin 模型锁 JVM 超时实测。完整 Android Gradle 编译与小米手机的真实长时间运行**尚未执行**。Android 不允许承诺被用户强制停止或厂商限制后仍能百分百自动重启。
