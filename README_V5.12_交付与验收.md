# 皮皮 PIPI V5.12.0｜Android Studio 整合工程

> 基于 **V5.11.1** 完整源码直接修改，不是 V5.6.2 的旧代码。包名仍为 `com.sprint7.offline`；Android `versionCode=29`、`versionName=5.12.0`。**本包为已修改、静态测试通过的源码交付，不是已经完成真机验收的 APK。**

## 已实装（不是仅有方案）

1. **学习数据防覆盖**：检测到手机旧记录存在但无法解析/结构异常时，首页停止写入并进入恢复保护界面；不再无提示地用空记录覆盖原数据。支持早期 `settingsVersion=1` 部分字段缺省的合法记录，主状态自动合并默认字段。
2. **自动恢复快照**：IndexedDB 存储带校验和的最近五个不同时间点的状态；即时作答和撤销入队存盘，书签变更也触发恢复快照。按写入顺序串行排队，避免先前的旧快照覆盖新记录。原有快照仍可读取。
3. **更安全的恢复**：统一在「工具 → 导出/恢复」页面做文件校验及失败回滚；新增「保存原始记录（异常数据应急）」入口。应急文件只用于保全原始数据，不能直接当作恢复备份导入。
4. **列表速背的业务修复**：真实手势滑过的单词原先只推进列表游标，**没有 FSRS 复习记录**。现在对滑过、未主动标记「不会」的词生成 FSRS 记录、今日统计和批次事件；主动标记「不会」的词不会被一次滑动误判为「会」。学习游标和复习记录一同持久化。
5. **复习页面性能**：生词本筛选改为预计算集合，避免大词表时对每个词反复扫描全部错题。
6. **阅读连续性**：保留 V5.11.1 句级柔和高亮及朗读跨章目录同步；补入阅读书签的自动恢复快照，独立阅读页异常主数据保护。
7. **统一版本号**：界面从 `app-version.js` 读取版本，Gradle 打包前按 `versionName` 更新此文件，修复 APK 与 UI 版本不一致的问题。
8. **交付检查**：新增 Windows 资源检查/构建脚本、代码测试脚本与 V5.12 回归测试。**保留 Piper 专用于单词、Kokoro 专用于原著**，没有引入第三种语音引擎、没有清空手机语音缓存，也没有更改 APK 包名。

## 仍有限制：不要把源码包误当完整 APK

- 当前运行环境验证 **9/10 部英文名著真实 TXT**、**7/7 类词书**、**256 个 ECDICT 分片**均存在或按上述数目核验；尚缺公版《汤姆·索亚历险记》的原始全文 `app/src/main/assets/books/tom.txt`。Windows 执行 `01_Windows_检查资源并构建APK.bat` 会调用项目已有的 `prepare_tom.py`，尝试从 Project Gutenberg #74 取得原文，核验 35 章后才继续。若目标电脑不能连接相关网站，需手动将 Gutenberg 74 的 **完整英文 UTF-8 原文**放到该路径并重新运行；**不可用缩写版代替**。
- ZIP 为源码交付，**不包含你本机已下载的 sherpa-onnx AAR、Piper/Kokoro 大模型**。Gradle 会从原有项目导入，默认查找 `%USERPROFILE%\Downloads\9 (2)`，失败时查找 `%USERPROFILE%\Downloads\3`，也可设置环境变量 `PIPI_VOICE_SOURCE`。**新 APK 完成后模型随 APK 安装，手机首次使用不用再下载。** 保留原工程，不删除旧模型或缓存。
- 目前环境没有完整 Android SDK/你的模型与手机，**没有跑出新的 Android APK**，无法保证安卓系统各厂商后台朗读、耗电/发热、Debug 签名以及真实连续听读无问题。
- `localStorage` 为当前同步主数据存储，IndexedDB 提供灾备快照，并未完成全面改造为以 Room 为主的数据库架构。数据量很大时仍有配额限制，应定期手动导出 JSON。此处不虚称为“数据库架构已彻底重构”。

## 推荐安装/使用（Windows）

1. **先从手机皮皮 → 工具 → 数据备份导出 JSON**；保留老手机上的 App 和学习记录，**不要卸载/清除数据**。
2. 完整工程包解压到一个**新的目录**（示例 `C:\Users\74787\Downloads\Pipi_V5.12`），不要覆盖旧的 `3` 或 `9 (2)` 工程。小补丁包只能覆盖其基准 **V5.11.1** 工程，**不能直接覆盖 V5.10 或更早工程**。
3. 双击 `01_Windows_检查资源并构建APK.bat`；会检查下载/模型/资源。若提示没有系统 Gradle 命令，改用 Android Studio 打开新目录，执行 `:app:assembleDebug`。
4. 编译通过后 APK 通常位于 `app\build\outputs\apk\debug\app-debug.apk`。**必须同包名、同签名**才能覆盖旧安装并保留数据。若出现签名不匹配，不要通过卸载旧版来解决，先核对旧 APK 签名与备份。
5. 真机使用飞行模式确认：7词书和10本书能打开、Piper 与 Kokoro 都能工作；原著连续听20分钟、手动翻章节、目录自动跟随、进后台后续播；完成1000词后继续第1001词；列表滑过后在 FSRS 中有后续复习记录；覆盖升级后学习记录和语音缓存无损。
