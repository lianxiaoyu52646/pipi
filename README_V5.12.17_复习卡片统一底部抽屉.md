## 本次真实代码改动
1. `app/src/main/assets/pipi-review-v51217.css` 专用底部复习抽屉，固定 82dvh 高度（较矮手机 87dvh），顶部固定、滚动正文、底部固定按钮，兼容 Android 安全区域。
2. 复习卡片英文、音标、语音按钮、来源和状态分层；中文释义、例句、原句与句译仅在按“显示答案”后显示。
3. 答题按钮改为“还不会 / 记住了”，FSRS 业务、SQLite 保存、主动收录规则原样保留；仅今日到期队列自动切到下一个单词，不会将生词本未到期词全部拉入复习。
4. 切换下一个单词时复用抽屉容器，避免重复上滑及高度跳变；同步更新页面当前到期数量。
5. 旧版错词复习入口也复用统一抽屉，不再使用旧式不等高表单。
6. 点击遮罩、关闭按钮、安卓返回和下拉抽屉顶部把手均可关闭；Esc 支持桌面调试。
7. 词条列表统一信息密度、英文和音标视觉层级；今日到期列表仍不提前展示释义。

## 设备验收建议
1. 分别进入“今日到期”、“生词本”、“全部”，点击每个列表单词检查统一弹层。
2. 先看英文和音标，确认中文及来源句译尚未出现；点击“显示答案”才显示。
3. 测试超长释义/多个原著来源，确认中部可滚动、底部评分按钮不会移动。
4. 在“今日到期”回答一个单词后，确认自动进入下一词且不重新弹出整张抽屉。
5. 在“生词本”点击一个未到期单词，回答后应退出该次卡片，不强制复习整个生词本。
6. 重启 App 核对 FSRS 到期日期、生词本收录和语音缓存进度均未丢失。
