# 皮皮 V5.12.2｜列表速背逻辑纠正

基于 V5.12.1 修改，保留 V5.12.1 的后台语音连续缓存修复。

## 正确产品行为

- **向下滑过默认视为会**：仅更新当前词书的浏览游标和“今日滑过”计数，不加入生词本，不创建 FSRS 记忆卡，不增加“今日复习”计数。
- **主动点击「＋ 不会」**：写入生词本，创建/更新 FSRS 记忆记录，按照算法安排复习。
- **8 秒内再次点按「↶ 撤销」**：还原本次新增的生词本和 FSRS 记录。
- **重新打开词书**：从已保存的下一个单词接着浏览；切换词书时各自记录进度。
- **不会因普通自动滚动、加载行或程序恢复游标而误判浏览进度**。

## 更新方法

如果已经使用 V5.12.1 的完整工程，先备份源码，再将 `Pipi_V5.12.2_UnknownOnly_ListFix_Patch_From_V5.12.1.zip` 解压到项目根目录，允许同名文件覆盖，然后用 Android Studio 重新编译 APK。**不是把 ZIP 整体放进 app 子文件夹**。

此补丁修改 `app/src/main/assets/app.js`、`app/src/main/assets/app-version.js`、`app/build.gradle` 及测试；不删除 Piper/Kokoro、本地词典或已存储的学习数据；Android 包名保留原值，版本号升级至 5.12.2（versionCode 31）。

## 已安装 V5.12.0 / V5.12.1 用户注意

之前错误逻辑已创建的“滑过即进入 FSRS”历史记录可能仍保存在手机本地。**本次修复阻止未来新增，但不自动批量删除已有 FSRS 记录**；因为旧数据未单独保存每个单词的来源，直接删除可能把真正手动复习过的记录一起误删。请先在 App 的备份页面导出记录，再单独核对需要清理的历史数据。
