# 皮皮 V5.12.11 · 复习模块8项完整整改

**基线**：V5.12.10 增量补丁已应用到 V5.12.9 完整项目。新补丁只适用于已更新到 V5.12.10 的源码工程。

## 8项优化
1. **P0 收录来源统一**：只有词书列表/词卡/原著点词中明确按「不会」，或在「全部」里主动确认收录，才创建 FSRS 卡片。抽测、听辨、听写中的答对、答错都只记录练习结果，不自动收录。对已有 FSRS 卡片，复习会/不会继续更新算法。
2. **P0 取消7次硬阈值**：FSRS 按记忆稳定度安排到期时间，不因答「会」次数将生词移除。生词的明确手动移除操作会保留历史在「全部」。
3. **P1 今日到期盲测**：到期列表只显示英文、音标等，先进入复习卡片，点「显示释义」后才能看到中文并判定。
4. **P1 分标签排序**：今日到期=到期时间升序；生词本=首次收录时间倒序；全部=单词拼写字母序（含历史待确认及手动移除项）。
5. **P1 大列表**：默认渲染70条，继续加载或靠近底部滚动会再加载70条；不再截断于200条。
6. **P1 连续到期复习**：按下「会／不会」后保存 FSRS 记录，弹出下一个到期单词，直到当次到期列表完成。
7. **P2 跨书来源**：一个生词保留不同原著的 bookId、书名、上下文句子，去重处理，打开复习卡片可查看来源。
8. **P2 实时检索**：输入实时筛选英文、中文、来源、原句；切换标签记住各标签的滚动位置。

## 升级与兼容
- 绝不要卸载原 App。更新前通过工具页导出学习数据 JSON，另外保留工程备份。
- 对历史记录采取保守方式：可判定为主动点不会的生词保留；旧版自动收录且无法证明来源的单词保留在「全部」显示为「待确认」，不自动加入 FSRS 到期队列，也不批量删除。你可在「全部」内手动确认收录。
- 仍复用 V5.12.9 的 SQLite 主学习数据库、兼容 WebView 镜像、20本原著、7套词书以及 Kokoro/Piper 离线语音缓存。升级 APK 请沿用之前相同的 applicationId 和签名。
- 大型语音模型和本地 AAR 不在发布包内，需要依照工程现有 README 从旧工程复用；不要删除旧语音缓存。

## 安装
**增量**：从 V5.12.10 工程根目录解压补丁（zip 内部已是 `app/` 与 `tests/` 路径），覆盖同名文件，Android Studio Sync 后编译安装。
**完整源码**：解压完整 ZIP，用 Android Studio 打开其中 `Pipi_V5.12.11_AndroidStudio` 目录；按工程现有 README 配置语音模型，再重新编译。
