皮皮 V5.2 / 内置考试词书来源说明

四级、六级、雅思、托福四套词书均来自本工程自带 ECDICT（256 个离线词典分片）的 g 分类标签和中文释义。
生成命令：python build_ecdict_tagged_wordbooks.py --force
生成后的词数：四级 3846 / 六级 5406 / 雅思 5038 / 托福 6970。
这些是社区词典的分类，不是教育部、考试院或 IELTS / TOEFL 官方发布的考试大纲。
为了保护旧用户数据，构建脚本默认不覆盖自行导入或已有的同名词书。
数据许可见 ECDICT_LICENSE.txt。无需联网即可打开全部词书并查询释义。
