# 皮皮 V5.10.8：Android Studio 整合工程（阅读朗读音质修复候选）

**建议：下载完整工程重新解压到新目录，不要叠加 V5.10.1～V5.10.7 的旧补丁。**

## 这次相对 V5.10.7 改了什么

- 停止 **在一句话中间压缩长静音**：保留 Kokoro 根据逗号、问号、感叹号做出的内部停顿和语气；之前硬剪静音可能产生机械停顿、字音切断。
- 对独立句子的音频头尾执行 12ms 余弦渐入渐出，避免 PCM 拼接的硬切换形成短促的爆音 / 点击声。仅裁去句首、句尾**确实接近静音**的多余空白，不切音素。
- 清理非有限音频采样并限制极端振幅，避免坏的 PCM 浮点数据转换成突发响声。
- Android 播放器调整：遇到合成暂时跟不上时，待当前已写音频播放完后暂停空轨；有下一段时先预写短片 PCM，再继续播放；缓冲不足时尝试补足短缓存。仍保留 V5.10.7 的按音频秒数预缓冲、音频缓存和词书行为。
- 将缓存内容版本键改为 `natural-envelope-v5108`：自动绕开旧版已经进行过激进裁剪的语音缓存，重新生成。

**音质边界**：本版降低硬剪静音和片段边缘爆音的风险，但不会把 Kokoro INT8 声码器变成真人录音。多句之间仍是独立生成，低性能设备上如果持续合成比播放慢，仍会有中途补缓冲。建议先选默认 Sarah 女声、语速 1.0× 对比 1.25×；更自然的连续韵律可能需要更高质量模型、段落级合成或预生成录音，须针对真实手机性能另行验证。

## 直接用 Android Studio 打包

1. 解压本 ZIP 到**一个全新的文件夹**，例如 `C:\Users\74787\Downloads\皮皮V5.10.8`。
2. **保留**你此前用来成功准备模型的原工程 `C:\Users\74787\Downloads\9 (2)`，不要删除、修改，也不要先卸载手机现有 App。
3. Android Studio 打开新工程根目录，等待 Gradle 同步完成，运行 `:app:assembleDebug`。
4. `app/build.gradle` 会在配置阶段尝试自动复制旧工程中 `app/libs/sherpa-onnx-1.13.8.aar` 和 `app/src/main/assets/tts/` 的 Piper、Kokoro 模型。如果原路径不同，添加 Gradle 参数 `-PpipiVoiceSource=旧工程完整路径`。
5. 如果语音模型/AAR 不完整，构建检查会**拒绝生成 APK**，请优先排查原工程文件。新 ZIP 本身未包含模型和 AAR。
6. 成功的 Debug APK 位置：`app/build/outputs/apk/debug/app-debug.apk`。安装之前先备份应用内学习记录，尽量覆盖安装，不要先卸载旧版本。

## 你应该在手机上验证

1. 打开英文原著，点击朗读，等待准备结束；听包含逗号、感叹号、引号和较长对话的连续 10 分钟。
2. 记录是否仍有：读到中间突然断声、嘶嘶/爆音、换句卡顿或尾声异常；同时测试 1.0× 和 0.75× 语速。
3. 暂停、继续、退出阅读、返回阅读、切换小说和音色，确认没有重叠发声或卡死。
4. 返回词书：静止 60 秒不跳动；手动滑过 20 词、退出重新进入，核对续学；点“不会”只进生词本。
5. 音质因设备而异。**如果第一次发声都失败，请优先核对最终 APK 的 Kokoro/Piper 资源**（项目内已有 `打包后检查语音是否完整.bat`）。
