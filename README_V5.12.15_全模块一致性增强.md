# 皮皮 V5.12.15 · 全模块一致性与历史数据增强

## 升级基线

此增量补丁仅适用 **V5.12.14 完整工程**。它不是给 V5.12.10/V5.12.11 直接使用的。请在 Windows 本地保留原 app 目录的语音模型和 AAR，先备份工程与导出学习记录 JSON，切勿卸载手机里已安装的 App。补丁解压后把 `app/`、`tests/` 等覆盖到工程根目录（同签名安装新 APK）。版本号升至 V5.12.15、versionCode 44。

## 修复和增强内容

1. **P0 离线词典**：统一 FSRS-6 调度，只有主动选择“不会”才创建新卡，“会”只能更新已收录卡；取消“满7次会自动归档”。SQLite 乐观并发写入，WebView 兼容镜像与校验快照仍保留。词典来源合并时保留原著旧记录的释义和来源。
2. **P0 词书词卡**：对已主动收录的生词，点击“会”会调用同一 FSRS 更新下次到期时间；未收录的词点击“会”不建卡。
3. **P0 书签合并**：备份页按每一本书的 `last` 时间而不是记录数，合并 SQLite 和 localStorage；阅读器及首页也从同一合并规则获取进度。时间戳相同优先 SQLite，不按阅读章节数大小判断，因为用户可能主动重读以前的章节。
4. **P1 并发安全**：Android SQLite 增加 `saveLearningStateIfRevision` 原子校验，防止多个 WebView 使用旧版本直接覆盖最新学习数据。发生冲突明确提示失败，请重新打开页面后操作；本版本不实现自动合并两个并发编辑分支。
5. **P1 写作**：提交后生成独立版本，保存完整正文、日期、字数和自检清单；写作页可查看最近20次提交的完整作文（旧历史未保存全文的无法补回）。作文提交失败时恢复本次未成功提交的统计变更；草稿仍有自动保存。
6. **P1 口语**：提交训练时将实际录音 Blob 保存到独立的本机 IndexedDB，历史列表可播放；原有训练次数和打卡记录保留。**重要：JSON 学习备份不包含录音音频**，重要录音应额外点击下载并妥善保存。Android 清除应用数据/卸载仍会删除该录音库。
7. **P1 原著阅读**：阅读页主学习状态保存也使用 SQLite 修订号校验，减少读写冲突导致的覆盖风险；阅读时对“已标记”词的显示与主动收录一致。
8. **备份失败回滚**：增加原生阅读书签单独清理接口，支持恢复失败时删除新建的 SQLite 书签数据。
9. 保留原20本完整原著、7套词书、256份 ECDICT 词典分片、Kokoro/Piper 离线朗读、后台缓存和断点续接架构。

## 尚未完成，不能宣称已修复

- **学习状态仍在 WebView 侧整份 JSON.stringify**，Android SQLite 只做分条增量写入。达到长期几万条练习事件后可能仍有序列化及12,000,000字符限制，真正全链路按字段更新需要独立迁移项目。
- 学习 JSON 导出/恢复不会自动备份录音库；录音请手工另存。也没有做音频多设备同步。
- Android 音频焦点、耳机拔出事件、完整 MediaSession 控件、8–12小时真机无人值守缓存/锁屏朗读，仍未验收。
- 动态180天计划、长期趋势统计、雅思训练更深分析及全面UI自动化验收，此版未新增。
- 新旧学习记录并发冲突现在**拒绝旧版本覆盖**；并非自动合并所有页面的修改。

## 安装与验证

1. V5.12.14 先打开“备份与恢复”导出JSON，并拷贝一份到电脑。
2. 关闭 Android Studio，复制本补丁到 `C:\Users\74787\Downloads\pipi` 根目录解压覆盖；确认 `app/src/main/java/com/sprint7/offline/StudyStateStore.java`、`MainActivity.java` 和 `app/src/main/assets/bookmark-merge.js` 都更新。
3. 保留现有本地 `app/libs/` 和 `app/src/main/assets/tts/`，原签名覆盖安装，不卸载旧版。
4. 执行 `gradlew.bat :app:assembleDebug :app:assembleDebugUnitTest :app:assembleDebugAndroidTest`；然后打开三处操作：词典标不会再连续标会、词书里已收录词标会、书签备份导出。
5. 朗读和背景缓存需在小米真机进一步检查。出现构建报错请发完整日志，勿清除手机应用数据。
