一、覆盖更新（只需复制文件，不需要运行 .bat）
1. 退出正在运行的皮皮 App。建议在当前 App 内先通过“导入/导出本机学习记录”备份一次。
2. 打开本更新 ZIP，找到里面的 app 文件夹，复制整个 app 文件夹。
3. 打开 C:\Users\74787\Downloads\1 ，粘贴 app 文件夹；Windows 如询问合并文件夹、替换同名文件，选“替换目标中的文件”。
4. 打开 Android Studio 中的原 Sprint7Offline 工程。
5. 点击 Build → Build Bundle(s) / APK(s) → Build APK(s)，等待 BUILD SUCCESSFUL。
6. 生成文件：C:\Users\74787\Downloads\1\app\build\outputs\apk\debug\app-debug.apk
7. 安装到手机：请直接覆盖安装旧版，不要先卸载；使用同一台电脑的调试签名，正常情况下旧版学习记录会保留。

二、新功能
• 手机页面按屏幕宽度自适应，修正右侧留白、顶部与底部导航拥挤。
• 手机桌面应用名、首页标题、词典与阅读器标题统一为“皮皮”。
• 训练 → 单词：先显示7本词书，点选直接进入当前词书单词卡片，支持返回词书列表。
• 每本词书都有独立的字母顺序游标。完成一次“会 / 不会”后才会前进，退出重开从下一词继续。各书互不干扰；FSRS 记忆间隔另外保存。
• 10本名著：按手机尺寸、字号重新分页；在英文阅读区左右滑动翻页，上下滚动照常工作；仍可点词查中文；独立保存每本书的章节与页内内容位置。
• 阅读支持字号调节、章节目录、上一页/下一页、轻微翻页动画。
