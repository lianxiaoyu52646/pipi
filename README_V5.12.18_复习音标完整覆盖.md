# 皮皮 V5.12.18 · 复习音标增强

升级基线：**V5.12.17**。解压补丁直接覆盖 Android Studio 工程根目录下的同名相对路径。不要卸载旧版 App 或清空学习数据。

## 已实现

- 今日到期 / 生词本 / 全部：统一在每个单词英文下方显示**音标**。
- 单词复习底部抽屉：英文、音标与发音按钮放在同一固定头部；显示中文释义前，音标也可见。
- 有词书自带音标时直接显示，无词书音标时使用**已随 App 离线打包的 ECDICT 词典**按需查询。
- 对 ECDICT 旧式转写的 `ә`、`'`、`:` 分别转换为更规范的 `ə`、`ˈ`、`ː`。示例：`ә'bændәn` → `/əˈbændən/`。
- 音标缺失时显示「暂无音标 · 可点发音」；不会出现空白、`undefined` 或无止境的加载提示。
- 音标异步查询复用、缓存；列表使用 IntersectionObserver 仅查询屏幕附近的行，避免几千生词一次性触发词典读取；旧 WebView 有滚动降级机制。
- 切换复习卡片时检查单词身份，防止异步回来的音标显示到下一词。
- 不修改 FSRS 状态、录入规则、SQLite 学习数据和背景语音缓存。

## 主要变更文件

- `app/src/main/assets/app.js`：复习列表、抽屉音标区绑定与惰性填充。
- `app/src/main/assets/pipi-review-phonetics.js`：**新增**，独立音标处理和离线词典查询。
- `app/src/main/assets/pipi-review-v51217.css`：音标字体、间距及统一最小行高。
- `app/src/main/assets/index.html`：注册音标脚本（在 app.js 之前）。
- `app/src/main/assets/app-version.js`、`app/build.gradle`：版本号升至 V5.12.18（versionCode 47）。
- `tests/test_v51218_review_phonetics.js`：专项回归测试。

## 如何验证

1. 在 V5.12.17 工程根目录覆盖本补丁；运行 `./gradlew.bat :app:assembleDebug`。
2. 直接覆盖安装，不卸载旧 APK，保持签名、SQLite、音频 PCM 目录不变。
3. 打开复习 → 今日到期 / 生词本 / 全部，检查英文下面是否显示音标。
4. 打开没有内置音标的旧生词；短暂加载后应出现离线音标；不在离线词典中的词会显示友好提示。
5. 滚动超过一页、点击复习 → 下一词，检查音标与对应英文匹配，中文仍默认隐藏。

## 已知验证边界

已通过 Node.js 自动化回归和真实 ECDICT 资源抽样校验；没有在本执行环境完成 Android SDK 构建/真实小米手机点触测试。自动化结果不能代替真机 UI 验收。离线词典不一定对每个罕见单词提供音标，缺失时保留发音按钮，不捏造转写。
