# 皮皮 V5.11.1 — 阅读高亮和朗读跨章目录修正

基于 V5.11 完整整合工程（Android 包名 `com.sprint7.offline`）。

## 修改内容
1. 当前朗读句子只显示柔和的背景高亮，不再给跨行文字画连续的下划线/阴影底线；对清爽白、暖纸、深色阅读主题均生效。
2. 朗读跨章节时，顶部目录标题及目录的紫色选中章节跟随正在发声的章节；打开目录会自动滚动到正在朗读的章节。
3. 手动滑动阅读时不改写朗读章节选择；停止朗读后目录恢复为当前可视阅读位置。增强 `aria-current` 无障碍状态。
4. 仅修改 WebView 阅读 UI、目录同步以及应用版本号，**未修改 Piper、Kokoro、声音缓存、后台服务、词书学习数据和语音资源**。

## 推荐更新方式：小补丁
- 先备份电脑上的 V5.11 工程以及手机学习数据。
- 解压 `皮皮_V5.11.1_阅读高亮和目录同步_补丁.zip` 到 V5.11 工程根目录，合并/覆盖 `app` 文件夹。
- Android Studio 运行 `:app:assembleDebug`，APK：`app/build/outputs/apk/debug/app-debug.apk`。
- Android 用同包名、同签名覆盖安装，不要先卸载旧 APK。

## 完整源码包
`皮皮_V5.11.1_AndroidStudio完整整合源码_不含本机语音模型.zip` 为独立工程源码，但**与此前版本一样没有内置用户本机的大体积 Piper / Kokoro 模型和 AAR**。构建配置可从指定的 `pipiVoiceSource=C:/Users/74787/Downloads/3` 导入旧工程语音文件；旧工程仍需保留，务必确认新 APK 中模型齐全。已有语音缓存保存在手机应用私有数据目录，不在工程 ZIP 中。

## 测试边界
- 已通过 JS 语法、目录选中函数动态测试（包括 Native TTS 跨章回调）、相关导航/分句回归测试。
